# Memos 一键复制内容

为 Memos 备忘录卡片增加独立的 `📋 复制内容` 按钮，省去打开 `⋮ → 复制 → 复制内容` 的步骤。

## 特点

- 一次点击即可复制备忘录的原始 Markdown 内容。
- 复用 Memos 自带的“复制内容”处理逻辑和成功提示。
- 不读取 React 私有属性，不发起网络请求，也不会上传备忘录内容。
- 自动处理单页应用跳转、列表加载和卡片重新渲染，避免重复添加按钮。
- 桌面端显示 `📋 复制内容`，宽度不超过 640px 时仅显示 `📋` 图标。
- 使用 Memos 的主题变量，支持浅色和深色主题。

## 兼容性

已在以下环境验证：

- Memos `0.30.0`
- Docker / 1Panel 部署

脚本依赖 Memos `0.30.0` 的语义化菜单属性和 Lucide 图标类。升级 Memos 后配置通常仍会保留，但前端结构可能变化，因此请重新测试复制按钮。

## 安装

1. 使用管理员账号打开 **设置 → 系统 → 自定义代码**。
2. 将 [`quick-copy-content.css`](./quick-copy-content.css) 的完整内容粘贴到“自定义样式”。
3. 将 [`quick-copy-content.js`](./quick-copy-content.js) 的完整内容粘贴到“自定义脚本”。只粘贴 JavaScript 源码，不要添加 `<script>` 标签。
4. 点击“保存”，然后刷新 Memos 首页。

每条备忘录右上角应该显示：

```text
📋 复制内容  ⋮
```

点击后，按钮会短暂显示“已复制”，同时出现 Memos 原生的“复制内容到剪贴板成功”提示。

## 升级与备份

通过 1Panel 正常升级 Memos 镜像时，自定义代码会随 Memos 数据库保留。升级前仍建议备份 Memos 数据目录或数据库；升级后刷新页面并测试一次复制功能。

如果按钮消失或显示“复制失败”，通常表示新版 Memos 调整了动作菜单结构，需要更新本脚本中的菜单定位逻辑。

## 卸载

回到 **设置 → 系统 → 自定义代码**，仅删除本项目对应的 CSS 和 JavaScript 后保存并刷新页面。

如果输入框中还包含其他自定义代码，请勿直接清空整个输入框。

## 文件

- `quick-copy-content.js`：添加按钮并调用 Memos 原生复制动作。
- `quick-copy-content.css`：按钮样式和移动端适配。
